Support

Peelback Mechanic

Email support@ramirezlabs.app and a person will reply. Include your device and iOS version, your vehicle's year and engine, and the code you were looking at.

What does this do that a code reader doesn't?

A reader gives you a code and a sentence. Neither tells you where the part is or what is sitting on top of it. Peelback Mechanic takes the code and pulls the engine apart on screen, layer by layer, so you can see which components that code actually implicates and what you would have to move to reach them. The question it answers is not what the code means but where it lives and how far in it is.

Which engines are supported?

One, deliberately. The Toyota 1GR‑FE V6, across the variants it shipped in. Every component in it was checked by hand against seventy-five parts and forty-three fault codes, and every link between a code and a component was verified rather than inferred. A database covering every vehicle would have been faster to assemble and would fall apart the moment you were under a hood with it.

Will you add my engine?

Probably, eventually, and the order depends on what people ask for. Email the year, make, model, and engine code. Each new engine means a 3D model and a hand-verified component map, so this is measured in engines per quarter rather than a list that grows overnight.

Does it need an OBD‑II adapter?

No. You can type a code in and get the same result. An adapter saves you the typing and lets you pull codes yourself, but nothing in the app is gated behind owning one.

It says a code touches five different components. Which one is broken?

Unknown, and the app will not pretend otherwise. A fault code reports a circuit or a reading that has gone out of range, and the cause could be any part of that circuit, including the wiring between the parts. What you get is the set of candidates and where each one sits, which is what narrows a diagnosis. Guessing one and calling it the answer is how parts get replaced for nothing.

Are there repair instructions?

No. This shows you the layout, not the procedure. Torque figures, sequences, and clearances belong in the factory service manual for your specific vehicle, which is the thing to work from once you know what you are reaching for.

Does it work in the driveway with no signal?

Yes. The models and the code data are bundled in the app. No connection is needed to look anything up.

The 3D model is slow or won't load.

Peeling a full engine apart is real work for the GPU. Close other apps and try again. On older hardware, the layer view drops detail to hold a usable frame rate, which is expected rather than a fault. If it fails outright, send your device model and what you were looking at when it happened.

Peelback Mechanic is a reference tool, not a repair manual. It does not tell you what is broken and it does not tell you how to fix it. Vehicle work carries real risk of injury and of expensive damage: follow the factory service manual for your vehicle, and if you are not confident, take it to someone who is.
